## ownjoo

*Say it out loud: "owned you."* A place for information security professionals to share
useful code, built by Jon in his spare time. Everything here is free and open source.

**Security and data tooling**

- **query_\*** CLIs for security platforms: CrowdStrike, Rapid7 InsightIDR and InsightVM, Sysdig,
  Checkmarx One, TruffleHog, Zafran and more. **[query-bench](https://github.com/ownjoo/query-bench)**
  is a container menu that installs any of them and drops you in a shell.
- **[packet-bench](https://github.com/ownjoo/packet-bench)**: a Docker toolbox for packet capture,
  crafting, HTTP proxying and network diagnostics.
- **[idp-auth](https://github.com/ownjoo/idp-auth)**: browserless SSO logins (SAML, vendor flows,
  TOTP and WebAuthn) over httpx.
- **[io-chains](https://github.com/ownjoo/io-chains)** and
  **[persistence](https://github.com/ownjoo/persistence)**: the async pipeline engine and storage
  layer behind ownjoo's ETL work.
- **[smb-mock](https://github.com/ownjoo/smb-mock)**: a Kerberos KDC and Samba server in Docker,
  for testing SMB clients without a domain controller.

**World of Warcraft addons**

- **[BG Comms](https://www.curseforge.com/wow/addons/bgcomms)**: one-click battleground callouts,
  pings and a live team map ([source](https://github.com/ownjoo/bgcomms)).
- **[CraftScout](https://www.curseforge.com/wow/addons/craftscout)**: every craft you know, ranked
  by live auction house profit.
